딥링크 동작 확인 페이지

두 가지 방식으로 앱을 열어 봅니다. 하나는 Airbridge 트래킹 링크, 다른 하나는 Android Chrome의 Intent URI 입니다. 아래 버튼을 눌러 각 경로가 실제 기기에서 어떻게 동작하는지 확인하십시오.

Method 01

Airbridge Link

Airbridge 트래킹 링크로 이동합니다. 앱 설치 여부에 따라 딥링크 또는 스토어로 분기됩니다.

https://abr.ge/t5kej8 Method 02

Chrome Intent

Android Chrome의 Intent URI로 앱을 직접 호출합니다. 앱이 없으면 폴백 URL로 이동합니다.

airbridge://second
