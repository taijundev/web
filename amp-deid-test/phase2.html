Phase 2 — 신규 버전 + 방안2

De-identification Test 2 프로젝트 API Key 로 초기화한다. 최초 실행이면 웹이 자체 캐싱해 둔 원문 User ID 를 읽어 가명화한 값만 Amplitude 에 전달하고, 2회차부터는 setUserId() 없이 신규 쿠키에 캐싱된 가명 ID 가 유지되는지 확인한다.

API Key 가 바뀌면 identity 쿠키 이름(AMP_{key 앞 10자})이 달라지므로, 신규 SDK 는 구 Key 의 쿠키를 읽지 않는다(삭제가 아니라 미참조 격리). 부수 효과로 device_id 가 새로 생성된다.
